# 🦄 Sipicorn

Unicorn-themed water tracker — React Native + Expo (TypeScript).

## Run

```bash
npm install
npx expo start
```

Then scan the QR code with **Expo Go** on your phone (or press `i` for the iOS simulator on a Mac, `a` for Android).

## Structure

```
App.tsx                     # entry, renders WelcomeScreen
src/theme/colors.ts         # "Cotton Candy Dream" palette
src/screens/WelcomeScreen.tsx
```
